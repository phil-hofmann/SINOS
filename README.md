# SINOS

Code accompanying the paper

**Mitigating Numerical Stiffness in Least-Squares Formulations of Elliptic PDEs for Physics-Informed Neural Networks**

This repository contains the numerical experiments for SINOS and D-SINOS, two Sobolev-norm loss formulations for physics-informed neural networks.

The experiments compare standard mean-squared-error losses with SINOS and D-SINOS for PDE problems with elliptic behavior, including Poisson and stationary incompressible Navier-Stokes equations.
